# 旧时风

> "我现在的样子……你还喜欢吗。"

---

一部第一人称中篇言情小说。严格 Galgame 式叙事视角，对话驱动，留白美学。

青梅竹马失踪三个月后，警察通知"我"去接人。站在警局门口的已经不是记忆中那个扎马尾、闻到烟味会皱眉的女孩——她穿着皮衣，叼着烟，锁骨上多了一只蝴蝶纹身。

"这三个月，比跟你在一起三年都快活。"

她外壳坚硬如石。他沉默笨拙如旧沙发。一碗皮蛋瘦肉粥，一盏黄灯，一条反复走过二十年的梧桐道。不是拯救，是站在旁边不走。

从"我来保护你"到"不管她变成什么样，她还是她。"

### 人物

- **"我"** — 22-23 岁，普通长相，戴眼镜。不善言辞。关心方式是"你饿不饿""冷不冷"。
- **黄依依** — 21 岁。被拐三个月后归来。外壳是刺，内核是渴望被确认，隐藏是无法言说的创伤。
- **母亲** — 48 岁，服装厂女工。沉默要强的人，爱从不落在嘴上，只落在饺子馅里。

### 写作特征

- 严格第一人称，不可跳视角
- 对话占比 ≥60%，省略对话提示词
- 情感反着写：越痛台词越短，情越大描写越少
- 留白与暗示：不解释每个动机，不填每个坑
- 象征物系统：蝴蝶、锁链、烟、饺子、梧桐树影、卫生间水声

### 内容提示

本作涉及创伤后应激障碍及被拐卖经历的相关暗示，主题为创伤后的重建与关系修复。
