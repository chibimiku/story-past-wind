# Galgame 行文写作规则

## 一、叙事视角
- **严格第一人称"我"**：不可跳视角，不能写"蝴蝶妹心里想""母亲暗自决定"。呈现他人内心只能通过"我"的观察。
- **独白规则**：有触发物才能开始（照片、一句话、场景）；口语化心声，不书面化。

## 二、对话驱动
- 对话占比≥60%，优先用对话推进情节。
- 单人发言≤3行，超过拆分为多次。
- 情绪激烈的对话反而更短——沉默、单字、断句。
- **省略对话提示词**，用人物标签+简短动作提示区分说话者。

## 三、旁白与描写克制
- 环境描写≤3句，每个环境元素必须服务于当前情绪。
- 只写能传递情绪的动作，不写功能性动作。
- **禁止直白描写被拐经历**，用身体反应、留白对话、象征物暗示。

## 四、情绪节奏
- 整体曲线：压抑→裂缝→崩溃→挣扎→重建
- 3分钟阅读内必须有一个情绪落点
- **情感反着写**：角色越痛，台词越短；情感越大，描写越少。

## 五、核心美学：留白与暗示
- 不解释每一个动机，不填每一个坑。
- 让读者在"没说的那部分"里感受重量。

## 六、象征物系统
| 象征物 | 含义 |
|--------|------|
| 蝴蝶纹身 | 被迫的身份，也代表活下来了 |
| 锁链纹身 | 被控制的记忆 |
| 歪歪扭扭的口红 | 扮演"大人"但手法拙劣 |
| 烟 | 隔开世界的屏障 |
| 饺子 | 母爱、家、过去的味道 |
| 梧桐树影 | 两人之间的距离与隔阂 |
| 卫生间水声 | 唯一能藏起来的时刻 |
| 金属碰撞声 | 她身上还有无法取下的东西 |
| 护住胸口 | 乳环仍在，每次触碰都是再经历穿刺 |
| 内衣阴干不晾 | 不能让任何人看见那些不属于她的东西 |

## 七、重复与变奏
"我现在的样子……你还喜欢吗？"
- 第一次（序章）：皮衣、抽烟、轻佻地问——外壳在试探
- 第二次（终章）：白T恤、没化妆、认真地看着——内心真的在等答案

## 八、"我"的语言特征
- 句子偏短，很少用修饰词，不讲大道理
- 情绪激动时话更少
- 关心的方式是"你饿不饿""冷不冷"这类笨问句
- 内心独白不要太诗意，保持口语化的诚实
