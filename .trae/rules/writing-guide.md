# Galgame 行文写作规则

## 一、叙事视角
- **严格第一人称"我"**：不可跳视角，不能写"蝴蝶妹心里想""母亲暗自决定"。呈现他人内心只能通过"我"的观察。
- **独白规则**：有触发物才能开始（照片、一句话、场景）；口语化心声，不书面化。

## 二、对话驱动
- 对话占比≥60%，优先用对话推进情节。
- 单人发言≤3行，超过拆分为多次。
- 情绪激烈的对话反而更短——沉默、单字、断句。
- **省略对话提示词**，用人物标签+简短动作提示区分说话者。

## 三、旁白与描写克制
- 环境描写≤3句，每个环境元素必须服务于当前情绪。
- 只写能传递情绪的动作，不写功能性动作。
- **禁止直白描写被拐经历**，用身体反应、留白对话、象征物暗示。

## 四、情绪节奏
- 整体曲线：压抑→裂缝→崩溃→挣扎→重建
- 3分钟阅读内必须有一个情绪落点
- **情感反着写**：角色越痛，台词越短；情感越大，描写越少。
- **情感推拉与错位**：两人感情发展存在"时间差"——她需要确认时他说不出口，他准备好了时她已经缩回去。让亲密感总是在"差点触到→又弹开"之间循环，制造持续的张力。关键场景中，一方靠近一步，另一方退半步，节奏由此产生。

## 五、核心美学：留白与暗示
- 不解释每一个动机，不填每一个坑。
- 让读者在"没说的那部分"里感受重量。

## 六、象征物系统
| 象征物 | 含义 |
|--------|------|
| 蝴蝶纹身 | 被迫的身份，也代表活下来了 |
| 锁链纹身 | 被控制的记忆 |
| 歪歪扭扭的口红 | 扮演"大人"但手法拙劣 |
| 烟 | 隔开世界的屏障 |
| 饺子 | 母爱、家、过去的味道 |
| 梧桐树影 | 两人之间的距离与隔阂 |
| 卫生间水声 | 唯一能藏起来的时刻 |
| 金属碰撞声 | 她身上还有无法取下的东西 |
| 护住胸口 | 乳环仍在，每次触碰都是再经历穿刺 |
| 内衣阴干不晾 | 不能让任何人看见那些不属于她的东西 |

## 七、重复与变奏
"我现在的样子……你还喜欢吗？"
- 第一次（序章）：皮衣、抽烟、轻佻地问——外壳在试探
- 第二次（终章）：白T恤、没化妆、认真地看着——内心真的在等答案

## 八、"我"的语言特征
- 句子偏短，很少用修饰词，不讲大道理
- 情绪激动时话更少
- 关心的方式是"你饿不饿""冷不冷"这类笨问句
- 内心独白不要太诗意，保持口语化的诚实

## 九、情绪压制与爆发
- **三不原则**：不解释、不抱怨、不邀功。角色的委屈、付出、牺牲，不通过台词说出来，而是通过行为和细节让读者自己发现。
- **情绪递进**：压抑感需要层层叠加——小委屈堆积成大情绪，不给读者"喘口气就能过去"的机会。一次沉默可以，三次沉默就是即将爆发的信号。
- **爆发点控制**：情绪累积到临界点时才释放。释放方式分两种：
  - **爆发式**（本作主要方式）：积累十次沉默，一次失控。如深夜电话、医院对话等关键场景。
  - **渗透式**：不爆发，而是让情绪像水渍一样慢慢洇出——适合日常场景中的温情时刻。
- **爆发后不解释**：情绪爆发之后，角色不会复盘、不会总结。写"她哭了很久"而不是"她哭是因为……"。留白在爆发之后更重。

## 十、人物弧光——从"保护"到"陪伴"
- **起点**："我"的默认姿态是保护——走马路外侧、问饿不饿、想替她挡住一切。保护欲里混着愧疚和未能言明的喜欢。
- **转折**：发现她需要的不是保护，是有人站在那里不离开。保护暗示她弱；陪伴承认她强。
- **终点**：从"我来保护你"到"不管她变成什么样，她还是她"。态度的转变不通过台词宣告，而是通过行为变化体现：
  - 前期："我"频繁走马路外侧（刻意保护）
  - 后期：不再刻意，但会在她需要时刚好站在旁边（自然陪伴）
- **女主角弧线**：外壳（刺人、粗话、抽烟）→ 裂缝（崩溃、噩梦、问"我是不是很脏"）→ 重建（不是变回从前，是成为混合了伤痕的新的人）
- **弧线写作规则**：不写"她变了""他成长了"。用动作和选择的改变来证明。前期她推开门就走，后期她推开门之前停一秒——这一个停顿就够了。

## 十一、情感层次递进——创伤后的亲密重建
- 创伤后的亲密不能跳跃式恢复，必须逐层递进：
  1. **允许共处一室**（最外层）：能坐着同一张桌子，但保持距离
  2. **允许看到她脆弱**：比如在她睡着时走进房间、看到她噩梦后不离开
  3. **语言上的信任**：开始问"你还喜欢我吗"——不是在试探，是真的在问
  4. **轻微的触碰**：递东西时刻意不碰到手指 → 某天不小心碰到，她没有缩手
  5. **主动靠近**（最深层）：她自己坐到你旁边，比如阳台两人并肩坐着
- **每跨越一层，需要足够的铺垫，不能跳级。**
- **退回比前进更常见**：跨出一步后，下一次场景会退回两三步。这不是重复，是创伤恢复的正常节奏。
- **写退回比写前进更重要**：退回的瞬间才是真正的情绪落点。比如她今天主动坐到你旁边，明天连门都不开——那个不开门的瞬间，写清楚门外的风声和门缝里漏出的灯光就够了。
